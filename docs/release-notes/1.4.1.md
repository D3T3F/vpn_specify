## What's new in 1.4.1

- **Per-process capture now follows child processes.** Apps built on WebView2, such as Dorion, do all their networking in `msedgewebview2.exe` children, which were not captured and so stayed outside the VPN. Every process started by a captured app is now captured too, for as long as it descends from that app. Other programs that use WebView2 (Teams, for example) are not affected.
- Connections already open in those child processes are dropped when the VPN connects, so they reconnect through the VPN.
- vpn_specify itself, and the helpers it starts for the tunnel, are never captured.
