## What's new in 1.5.0

- **macOS (experimental).** vpn_specify now builds for macOS, on Apple Silicon and Intel: `vpn_specify-1.5.0-macos-arm64.tar.gz` and `vpn_specify-1.5.0-macos-amd64.tar.gz`. It has the same browser interface as Linux, the SOCKS5 and HTTP proxies, WireGuard, and OpenVPN (install it with `brew install openvpn`; the administrator password is asked when an OpenVPN tunnel starts). Launch at login uses a launchd agent. Per-process capture stays Windows only. This is the first release for the Mac and it has not been tested on a real Mac yet, so please report problems as GitHub issues. The binary is not notarized: run `xattr -dr com.apple.quarantine vpn_specify` after extracting it (see the README).
- **Updating on Windows no longer fails on the WinDivert driver.** The installer used to stop with "could not replace ...\windivert\WinDivert64.sys (Access is denied)" when the driver was loaded. Files that are identical to the installed ones are now skipped, and a changed driver is replaced after its service is stopped.
- **Releases are built automatically** by GitHub Actions: Windows installer, Linux, macOS and the signed Android APK, with a `SHA256SUMS.txt`.
- The new messages are translated into the 9 other languages.
