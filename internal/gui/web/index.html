Desconectado

Conexão

Só os apps abertos pelo vpn_specify usam a VPN. O resto do computador continua na rede normal.

VPNs

Os arquivos (.ovpn / .conf) são copiados para a pasta de dados do vpn_specify. Use “Editar” para renomear ou alterar a configuração.

Apps na VPN

Use “Criar atalho” para ter, por exemplo, “DiscordVPN” na pesquisa do Windows ao lado do Discord original.
