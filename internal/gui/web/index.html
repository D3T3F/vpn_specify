vpn_specify

Connection

Only the apps opened by vpn_specify use the VPN. The rest of the computer stays on the normal network.

VPNs

The files (.ovpn / .conf) are copied into the vpn_specify data folder. Use “Edit” to rename or change the configuration.

Apps in the VPN

Use “Create shortcut” to get, for example, “DiscordVPN” in Windows search next to the original Discord.

Use “Create shortcut” to get, for example, “DiscordVPN” in the applications menu next to the original Discord.
